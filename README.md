# 台灣山岳氣象地圖 tw-hiking-forecast

把中央氣象署（CWA）的雷達回波、雨量、定量降水預報（QPF）、測站觀測、登山/育樂景點預報、鄉鎮預報、地震報告、颱風警報與風雨預測整合在一張地形圖上，供登山安全評估使用。網頁本身就是 PWA，可「加到主畫面」當 App 使用，最近查詢的資料可離線瀏覽。

設計與資料來源規劃見 [docs/PLAN.md](docs/PLAN.md)。

## 功能

| 類別 | 內容 |
|---|---|
| 疊圖（可調透明度/濃淡） | 雷達回波（近 1 小時 10 分鐘動畫）、過去 1 小時雨量、累積雨量（今日／過去 3、6、12、24 小時／2、3、7 天，雨量站內插）、未來 1 小時雨量、定量降水預報（12 小時 × 4；颱風警報期間另有 6 小時 × 8；未來 24／48 小時加總，標示為衍生資料）、溫度分析、風力（鄉鎮預報依蒲福風級著色＋登山預報點風向箭頭，3 小時一步可拖動；或測站即時觀測）、閃電（過去 1 小時，依時間著色，區分對地／雲間）、衛星雲圖（紅外線黑白／色調強化／可見光，由數值重新著色並平滑顯示）、颱風 24 小時與總雨量預測（警報期間） |
| 圖例 | 位於地圖右下角，收合時只顯示單位（例：單位 mm）、時間與直式色帶，圖層名稱在展開後顯示，點開列出完整級距與資料說明；雨量圖例預設為氣象署小間距原色階（1、2、6、10…300 mm 以上），使用者可自行切換為大間距（1、10、20、60、100…2000 mm，自訂色階：藍→綠→黃橘→紅→紫→洋紅→淡紫→藍灰→近黑，300 mm 以上不再與 150–300 mm 的洋紅混淆；色弱友善色盤為依雨量遞減明度的連續色階、高對比色盤為黑黃白階層），不會自動切換，最大值超過 300 mm 時提示可改選大間距 |
| 地圖標記 | 依序為「觀測站、地震、颱風／有預報的山、景點／所有山頭」。觀測站白點為氣象站、淺藍為雨量站；地震以橘色圓章標示規模（24 小時內為深橘白框）；有登山預報的山為實心深棕 ▲，位置已校正到 OSM 山頂（氣象署座標可能偏差數公里，5 km 內同名山頭視為同一座，只顯示有預報的那個）；所有山頭為空心 △（OSM，10 級起依海拔由高到低顯示）；選項內「圖示說明」列出所有圖示、景點（依氣象署 14 類分類以不同圖示顯示，選項內附圖示說明）、地震、颱風；山岳／景點／山頭名稱預設顯示（9～10 級起，自動避免重疊），測站名稱 11 級起；各組有「全選」「全部取消」 |
| 選項（地圖右上角） | 透明度、地圖名稱字體（拖動即時套用）、標記與名稱開關（各組有全選／全部取消）、景點圖示說明、列出受影響山區、文字版／圖示版切換；其他顯示設定（字體大小、主題、色盤、粗體、減少動畫、底部圖層列）在「設定」 |
| 底部圖層列 | 可按「▾ 收合」讓地圖更大，收合後地圖左下角的「▴ 圖層」按鈕可再展開，狀態會記住 |
| 收藏與選取 | 面板標題列的 ☆ 可隨時收藏／取消收藏目前地點，搜尋結果每一列右側的 ☆ 可直接收藏、不必開啟；收藏會記住是哪座山／測站，從收藏開啟時回到同一個面板。選取的地點在地圖上以粉紅光圈標示（面板關閉後移除），若被面板遮住會自動平移到可見範圍 |
| 定位 | 按定位鈕後在地圖上以白點（含 GPS 精度圈）標示目前位置，並開啟該地資訊 |
| 點擊地圖任一處 | 顯示被點的那一點本身（不會再自動跳到附近的山頭）：所在鄉鎮、登山安全評估燈號（列出觸發原因；含 15 km 內閃電、登山預報 24 小時內 6 級以上風力）、該點格點值、QPF 四時段、登山/景點預報（點選有預報的山或景點標記、搜尋結果、收藏時顯示；3 天逐 3 小時、一週逐 12 小時）或鄉鎮預報，面板標題列下方以小字提示「非預報點」或「無氣象署預報」，並列出 15 km 內最近 3 座預報山頭的未來 24 小時概況（天氣、溫度、降雨機率、風與陣風）可再點開看完整預報、鄰近測站即時值、測站歷史圖表（24 小時 / 3 天 / 7 天 / 31 天 / 自訂區間）、近期地震、警特報 |
| 反向查詢 | 「列出受影響山區」：目前圖層超過門檻的山或景點清單（依強度排序） |
| 地震 | 24 小時內有感地震顯示警告條（圖示版另有「地震」分頁）；強震（最大震度 5 弱以上或規模 6 以上，3 天內）在震央顯示閃動圖示，點開為地震報告、強震注意事項與氣象署報告圖；震央、10/30/50 km 範圍圈、氣象署等震度圖（自動對位疊合，最新一筆顯著地震）、各測站實測震度、範圍內的山與景點；面板降低高度並自動縮放到有感範圍 |
| 颱風 | 警報期間才出現警告條與颱風分頁；開啟網站時自動顯示颱風圖層，臺灣維持在畫面正中央，必要時最多縮小一級讓颱風進入畫面；路徑（實際/預測）、7 級與 10 級風暴風圈、70% 機率半徑、警報全文；各地區風力、24 小時與總雨量預測（平地/山區）需開啟 `TYPHOON_TABLES`，見下方授權說明 |
| 地點預報 | 氣象署 14 類育樂景點預報（登山 151 處、國家公園、森林遊樂區、農場、水庫、海水浴場…）＋全台 368 鄉鎮 |
| 手機版面 | 底部面板可上滑展開／下滑收合；手機橫放改為側邊面板；所有按鈕觸控範圍 ≥ 44px、字級 ≥ 12px；於 360/390/412 寬直式、740 橫式、768 平板驗證 |
| 無障礙 | 字體 90–200%、淺色/深色/高對比主題、色盤（氣象署原色/色弱友善/高對比）、粗體、減少動畫、鍵盤操作、螢幕報讀（圖表附摘要與數據表、燈號不只靠顏色） |
| 離線 | App 外殼、最後一次資料、瀏覽過的底圖圖磚自動快取；最近 40 筆查詢可離線開啟；可預先下載目前範圍底圖 |

## 架構

```
CWA 開放資料 S3 (cwaopendata, 免金鑰)
   │  GitHub Actions 每 20 分鐘
   ▼
pipeline/ (Python)  ── 轉成精簡格式 ──►  site/data/  ──►  GitHub Pages (PWA)
   ├ grids.py    格點 → 16-bit PNG（TWD67→WGS84 校正）
   ├ qpf.py      QPF 圖片 → 自動地理對位 + 由圖例色彩反推雨量級距
   ├ shakemap.py 等震度圖 → 自動地理對位 + 由圖例色彩反推震度
   ├ rainacc.py  雨量站 3 小時～7 天累積 → 距離權重內插網格
   ├ qpfacc.py   6 小時定量降水格點（F-C0041）與 24／48 小時加總
   ├ satellite.py 向日葵亮度溫度／反照率 GeoTIFF（蘭伯特投影）→ 經緯度網格
   ├ stations.py 測站即時值 + 逐時歷史封存（月檔 CSV.gz）
   ├ forecast.py 景點/鄉鎮預報
   ├ gusts.py    陣風預報（Open-Meteo 數值模式，每小時更新；氣象署預報沒有陣風）
   ├ wind.py     鄉鎮與登山預報點 3 小時風力摘要：平均風、風向、陣風、體感溫度（wind.json）
   ├ lightning.py 閃電 KMZ（O-A0039-001）→ lightning.json
   ├ peaks.py    OSM 山頭 + 所在鄉鎮 + 清單標記
   └ hazards.py  地震、颱風、警特報
```

* 定量降水預報只提供圖片、沒有座標：以縣市界線（taiwan-atlas，內政部資料）對圖上的黑色界線做 chamfer matching 求出像素↔經緯度轉換，每次執行都會驗證，版面改變時自動重新擬合；再把圖例的 17 種顏色反推回雨量級距，前端即可用任何色盤重繪並點擊查值。
* 測站歷史：S3 `history/` 保留約 15 天逐時資料，pipeline 首次執行時回補，之後每次累積到 `archive/YYYY-MM.csv.gz`，網站提供近 31 天逐站檔，更早的區間由瀏覽器下載月檔解壓查詢。

## 本機執行

```bash
python3 -m pipeline.build            # 自動建立 .venv 並安裝 requirements.txt，輸出到 site/data/
python3 -m http.server -d site 8000  # 開啟 http://localhost:8000
```

常用參數：`--only stations,grids,qpf`（只跑部分任務）、`--history-days 15`（回補天數）。
每次執行都會在 `logs/` 產生紀錄檔，第一行為重現指令。

## 測試

```bash
.venv/bin/python -m pytest -q tests          # pipeline 單元測試（真實 CWA 資料裁切成的 fixtures）
node tests/e2e/run_e2e.cjs                   # 前端端對端測試（Playwright/Chromium，需先 build）
node tests/e2e/mobile_audit.cjs              # 手機版面檢查：5 種螢幕尺寸的溢出、觸控目標 ≥44px、字級 ≥12px
eslint site/js site/sw.js tests/e2e          # 前端 lint
```

## 部署（GitHub Pages）

1. Repository → Settings → Pages → Source 選 **GitHub Actions**。
   （私人 repository 需 GitHub Pro 以上才能使用 Pages；公開 repository 免費且 Actions 分鐘數不限。）
2. `.github/workflows/build-deploy.yml` 會每 20 分鐘抓資料並部署，也可在 Actions 頁面手動執行。
3. 目前所有資料皆取自氣象署公開 S3，不需要 API 授權碼。若之後加入僅 REST API 提供的資料，請把授權碼放在 Settings → Secrets → Actions 的 `CWA_API_KEY`，**不要寫進程式碼或 commit**。

## 資料來源與授權

* 中央氣象署開放資料，依[政府資料開放授權條款](https://data.gov.tw/license)利用；網站內「資料來源與授權」頁列出各資料集與顯名聲明。由本網站加工的衍生資料（24／48 小時累積降水等）均標示「非中央氣象署發布之預報」。
* 颱風各地區風力／24 小時雨量／總雨量預測表附有氣象署著作權聲明（未經書面授權不得向公眾提供），因此**預設不輸出**，網站改提供[氣象署颱風消息](https://www.cwa.gov.tw/V8/C/P/Typhoon/TY_NEWS.html)連結。個人使用可執行 `python -m pipeline.build --typhoon-tables`；取得授權後在 GitHub Actions Variables 設定 `TYPHOON_TABLES=1` 即可在網站顯示。申請進度見 [docs/TODO.md](docs/TODO.md)。
* 行政區界：[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（MIT，資料來源內政部）。
* 地圖：Leaflet（BSD-2）、OpenTopoMap（CC-BY-SA）、OpenStreetMap、內政部國土測繪中心；OpenCycleMap／Landscape／Outdoors（Maps © Thunderforest，需 API key：在 Actions Variables 設定 `THUNDERFOREST_KEY`，或在網站「設定 → 底圖」填入個人 key；未設定時改用等高線地形圖）。
* 陣風預報：[Open-Meteo](https://open-meteo.com/)（CC BY 4.0，免金鑰、非商業使用），標示為模式預報、非氣象署發布；顯示在風力圖層說明、登山／鄉鎮預報表的「陣風」列，並納入安全評估。測站體感溫度以氣象署公式（溫度、濕度、風速）估算並標示「估算」。
* 山頭：© OpenStreetMap contributors（ODbL），建置時由 Overpass API 取得 `natural=peak`，每週更新；與氣象署登山預報點同名且 5 km 內者視為同一座、只顯示有預報的那個；下載範圍涵蓋福建沿海，不在臺灣任何鄉鎮界內的山頭（例如福建的同名山）會被剔除。每座山頭附所在縣市鄉鎮（內政部行政區界，經 taiwan-atlas；位於界線 0.4 km 內的山同時列出兩邊，例如「臺中市和平區／苗栗縣泰安鄉」），搜尋結果與面板都會顯示，方便分辨同名山。
* 山頭分類（百岳、小百岳等）：在 `pipeline/data/peak_lists/` 放清單 JSON 即會在建置時標記，格式見該資料夾 README；更新清單不需重新下載 OSM。
* 本工具的安全評估為自動規則判斷，僅供參考，請以現場狀況與官方資訊為準。
