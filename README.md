# 台灣山岳氣象地圖 tw-hiking-forecast

把中央氣象署（CWA）的雷達回波、雨量、定量降水預報（QPF）、測站觀測、登山/育樂景點預報、鄉鎮預報、地震報告、颱風警報與風雨預測整合在一張地形圖上，供登山安全評估使用。網頁本身就是 PWA，可「加到主畫面」當 App 使用，最近查詢的資料可離線瀏覽。

設計與資料來源規劃見 [docs/PLAN.md](docs/PLAN.md)。

## 功能

| 類別 | 內容 |
|---|---|
| 疊圖（可調透明度/濃淡） | 雷達回波（近 1 小時 10 分鐘動畫）、過去 1 小時雨量、累積雨量（今日／過去 3、6、12、24 小時／2、3、7 天，雨量站內插）、未來 1 小時雨量、定量降水預報（12 小時 × 4；另有逐 6 小時 × 8，平時由氣象署全球資訊網每日發布的預報圖解碼〔標題文字辨識發布與有效時間，辨識不確定時不顯示〕，失敗時改用開放資料 F-C0041〔僅陸上颱風警報期間提供〕，圖例標明來源；未來 24／48 小時加總，標示為衍生資料）、溫度分析（陸地 3 km 格點，外推沿海缺值後以真實海岸線裁切）、風力（鄉鎮預報依蒲福風級著色＋登山預報點風向箭頭，3 小時一步可拖動；或測站即時觀測）、閃電（過去 1 小時，依時間著色，區分對地／雲間）、降雨機率（鄉鎮 3 小時）、紫外線（鄉鎮逐日）、能見度（測站觀測／模式預報，含濃霧提示）、水位（水利署河川水位站與水庫放流狀態）、土石流警戒（鄉鎮著色）、風力圖層的「高空風」模式（氣象署 WRF 區域模式 15 km 全場箭頭，可選約 800／1,600／3,200／5,900 m 四個海拔，每 6 小時至 72 小時；海拔與氣壓層 hPa 分開標示）、風力圖層「高空風」另可切換 WRF 3 km（M-A0064，含 10 m 地面風與 7 個氣壓層，每 6 小時至 84 小時，顯示時降採樣約 6 km）、WRF 3 km 圖層（6 小時降水、2 m 氣溫，每 6 小時至 84 小時，標示為模式輸出）、全球模式圖層（氣象署 M-A0060，0.25°，16 天：24 小時降水、海平面氣壓、2 m 氣溫，每天一格，可播放；點位卡片為 16 天氣溫、降水、風速趨勢，標示為模式輸出）、模式預報圖層（降雨、風、氣溫、氣壓：氣象署 WRF 3 km、ECMWF IFS、ECMWF AIFS〔AI 模型〕、NOAA GFS 同一個畫面切換，6 小時降雨、10 m 風、2 m 氣溫與海平面氣壓〔WRF 3 km 無氣壓〕、每 6 小時一步至 10 天，時間軸共用且切換模式時保持同一時間，25 km 模式標示山區偏差的紅字警語；降雨另有「捲簾」〔兩個模式左右可拖動分隔線比較〕、「差值」〔第二個減第一個，橙＝偏乾、藍＝偏濕，同一個 0.05° 格網取樣〕、「一致度」〔各模式 6 小時降雨達 10 mm 的模式數，僅降雨〕，氣溫與氣壓可用捲簾與差值，僅取各模式共同的預報時間），熱傷害指數（鄉鎮逐 3 小時 5 天，氣象署 M-A0085，點位卡片含警示時段並納入登山安全評估）、NASA 影像圖層（NASA GIBS 每日 MODIS Terra 真彩色約 250 m、積雪指數約 500 m，瀏覽器直接載入圖磚，可選今天至前 6 天，預設昨天；標示 NASA GIBS／ESDIS 來源，警語：雲下與夜間無資料、今天影像常不完整）、衛星雲圖（紅外線黑白／色調強化／可見光，夜間可見光無資料會註明，由數值重新著色，0.01° 網格雙線性取樣，色調強化採氣象署彩色配色，預設不透明度 100%，可用滑桿／播放查看過去 6 小時的影像（每 20 分鐘一格〔與建置同步，最短間隔 15 分鐘〕，開放資料只提供最新一張，歷史由每次建置累積保存），疊加台灣本島、離島及縣市輪廓線；開放資料原生解析度約 1.9 km，氣象署網站的更細緻影像需另行授權）、颱風 24 小時與總雨量預測（警報期間） |
| 圖例 | 位於地圖右下角，收合時只顯示單位（例：單位 mm）、時間與直式色帶，圖層名稱在展開後顯示，點開列出完整級距與資料說明；雨量圖例預設為氣象署小間距原色階（1、2、6、10…300 mm 以上），使用者可自行切換為大間距（1、10、20、60、100…2000 mm，自訂色階：藍→綠→黃橘→紅→紫→洋紅→淡紫→藍灰→近黑，300 mm 以上不再與 150–300 mm 的洋紅混淆；色弱友善色盤為依雨量遞減明度的連續色階、高對比色盤為黑黃白階層），不會自動切換，最大值超過 300 mm 時提示可改選大間距 |
| 地圖標記 | 依序為「觀測站、地震、颱風／有預報的山、景點／所有山頭」。觀測站白點為氣象站、淺藍為雨量站；地震以橘色圓章標示規模（24 小時內為深橘白框）；有登山預報的山為實心深棕 ▲，位置已校正到 OSM 山頂（氣象署座標可能偏差數公里，5 km 內同名山頭視為同一座，只顯示有預報的那個）；所有山頭為空心 △（OSM，10 級起依海拔由高到低顯示）；選項內「圖示說明」列出所有圖示、景點（依氣象署 14 類分類以不同圖示顯示，選項內附圖示說明）、地震、颱風；山岳／景點／山頭名稱預設顯示（9～10 級起，自動避免重疊），測站名稱 11 級起；各組有「全選」「全部取消」 |
| 顯示（地圖右上角，眼睛圖示） | 透明度、地圖名稱字體（拖動即時套用）、標記與名稱開關（各組有全選／全部取消）、景點圖示說明、列出受影響山區、文字版／圖示版切換；其他顯示設定（字體大小、主題、色盤、粗體、減少動畫、底部圖層列）在「設定」 |
| 時間軸 | 有時間軸的圖層（雷達、預報、衛星雲圖等）在滑桿兩側有「‹ 上一個時段／下一個時段 ›」按鈕（與播放鈕同一列，不佔額外高度，到頭自動停用），滑桿本身可用鍵盤方向鍵 |
| 底部圖層列 | 圖層按鈕列最右端的圓形 ▾ 可收合圖層列讓地圖更大，收合後地圖左下角的「▴ 圖層」按鈕可再展開，狀態會記住；比例尺位於「圖層」按鈕上方 |
| 收藏與選取 | 面板標題列的 ☆ 可隨時收藏／取消收藏目前地點，搜尋結果每一列右側的 ☆ 可直接收藏、不必開啟；收藏會記住是哪座山／測站，從收藏開啟時回到同一個面板。選取的地點在地圖上以粉紅光圈標示（面板關閉後移除），若被面板遮住會自動平移到可見範圍 |
| 定位 | 按定位鈕後在地圖上以白點（含 GPS 精度圈）標示目前位置，並開啟該地資訊 |
| 點擊地圖任一處 | 顯示被點的那一點本身（不會再自動跳到附近的山頭）：所在鄉鎮、登山安全評估燈號（列出觸發原因；含 15 km 內閃電、登山預報 24 小時內 6 級以上風力）、該點格點值、QPF 四時段、登山/景點預報（點選有預報的山或景點標記、搜尋結果、收藏時顯示；3 天逐 3 小時、一週逐 12 小時）或鄉鎮預報，面板標題列下方以小字提示「非預報點」或「無氣象署預報」，並列出 15 km 內最近 3 座預報山頭的未來 24 小時概況（天氣、溫度、降雨機率、風與陣風）可再點開看完整預報、鄰近測站即時值、測站歷史圖表（24 小時 / 3 天 / 7 天 / 31 天 / 自訂區間）、近期地震、警特報 |
| 點位面板版面 | 標題列下方右側為「Windy／座標／收藏」按鈕；其下為摘要列（安全等級、降雨機率、氣溫與體感、風級與陣風；取「目前所在 3 小時預報時段」，下方小字標明來源〔地點預報／鄉鎮預報／鄰近山頭預報〕與時段）與區段跳轉鈕；內容分為 7 區、每區一種主題色的可折疊卡片：安全（紅）、觀測（藍）、預報（綠）、高空（紫）、水情（青）、日照（黃）、資訊（灰）。卡片順序：…鄰近測站、高空風、地點預報、鄰近山頭預報、鄉鎮預報…；沒有氣象署山頭預報的點，鄉鎮預報預設展開；模式類資料的警語（山區偏差、陣風低估、行走風險等）以紅字顯示；系集預報等圖表的標題與圖例分行顯示；折疊時標題列仍顯示一行摘要；有警示的卡片自動展開，其餘展開／折疊狀態會記住；「全部展開／全部收合」；歷史資料併入「鄰近測站」卡，名稱為「觀測資料」（逐時數值、圖表、數據表，第一次展開才載入） |
| 點位面板的預報資料 | 鄰近 15 km 河川水位站與水庫、所在鄉鎮的土石流警戒；高空風（登山預報點 925／850／700／500 hPa 風向風速）、能見度、紫外線、凍結高度（Open-Meteo 數值模式）；日出日沒（依經緯度與海拔計算，含民用曙暮光）；系集預報（10 天，ECMWF IFS、ECMWF AIFS〔AI 模型〕與 GFS 的中位數與 10–90% 範圍，按鈕後由瀏覽器連線 Open-Meteo 取得） |

## 架構

```
CWA 開放資料 S3 (cwaopendata, 免金鑰)
   │  GitHub Actions 每 20 分鐘
   ▼
pipeline/ (Python)  ── 轉成精簡格式 ──►  site/data/  ──►  GitHub Pages (PWA)
   ├ grids.py    格點 → 16-bit PNG（TWD67→WGS84 校正）
   ├ qpf.py      QPF 圖片 → 自動地理對位 + 由圖例色彩反推雨量級距
   ├ shakemap.py 等震度圖 → 自動地理對位 + 由圖例色彩反推震度
   ├ rainacc.py  雨量站 3 小時～7 天累積 → 距離權重內插網格
   ├ qpfacc.py   6 小時定量降水格點（F-C0041）與 24／48 小時加總
   ├ satellite.py 向日葵亮度溫度／反照率 GeoTIFF（蘭伯特投影）→ 經緯度網格
   ├ stations.py 測站即時值 + 逐時歷史封存（月檔 CSV.gz）
   ├ forecast.py 景點/鄉鎮預報
   ├ gusts.py    鄉鎮陣風預報（Open-Meteo 數值模式，每小時更新；氣象署預報沒有陣風；登山預報點不提供，因模式網格高度遠低於山頂會低估）
   ├ hydro.py    水利署河川水位／水庫水情與水保署土石流警戒（hydro.json）
   ├ wrf3.py     氣象署 WRF 3 km（M-A0064，每檔約 180 MB，新模式起報才下載，約 2.5 分鐘）：2 m 氣溫／6 小時降水格點 PNG、風場（wrf3.json）、景點與鄉鎮時間序列（wrf3pts.json）
   ├ wrfglobal.py 氣象署全球模式（M-A0060，每檔約 60 MB、52 個時次，新模式起報才下載，約 4～5 分鐘）：東亞 24 小時降水／海平面氣壓／氣溫格點 PNG 與景點、鄉鎮時間序列（wrfgpts.json）
   ├ modelgrid.py ECMWF IFS／AIFS（open-data S3）與 NOAA GFS（S3）：只以 byte range 下載 6 小時降雨與 10 m 風兩個欄位，輸出 mm_<模式>_rain_<hhh> 格點與 mm_<模式>_wind.json；新模式起報才處理
   ├ heat.py     熱傷害指數預報（M-A0085）→ heat.json
   ├ wrf.py      氣象署 WRF 區域模式（M-A0061 GRIB2，pygrib）高空風場，新模式起報才下載（wrf.json）
   ├ aloft.py    登山預報點高空風、能見度、紫外線、凍結高度（Open-Meteo 數值模式，每小時更新；aloft.json）
   ├ wind.py     鄉鎮與登山預報點 3 小時摘要：平均風、風向、陣風、體感溫度、降雨機率、紫外線（wind.json）
   ├ lightning.py 閃電 KMZ（O-A0039-001）→ lightning.json
   ├ peaks.py    OSM 山頭 + 所在鄉鎮 + 清單標記
   └ hazards.py  地震、颱風、警特報
```

* 定量降水預報只提供圖片、沒有座標：以縣市界線（taiwan-atlas，內政部資料）對圖上的黑色界線做 chamfer matching 求出像素↔經緯度轉換，每次執行都會驗證，版面改變時自動重新擬合；再把圖例的 17 種顏色反推回雨量級距，前端即可用任何色盤重繪並點擊查值。
* 測站歷史：S3 `history/` 保留約 15 天逐時資料，pipeline 首次執行時回補，之後每次累積到 `archive/YYYY-MM.csv.gz`，網站提供近 31 天逐站檔，更早的區間由瀏覽器下載月檔解壓查詢。

## 本機執行

```bash
python3 -m pipeline.build            # 自動建立 .venv 並安裝 requirements.txt，輸出到 site/data/
# requirements.txt 是附雜湊的鎖定檔（pip 會驗證每個套件），由 requirements.in 產生：
#   pip install pip-tools && pip-compile --generate-hashes --allow-unsafe -o requirements.txt requirements.in
python3 -m http.server -d site 8000  # 開啟 http://localhost:8000
```

常用參數：`--only stations,grids,qpf`（只跑部分任務）、`--history-days 15`（回補天數）。
每次執行都會在 `logs/` 產生紀錄檔，第一行為重現指令。

## 測試

```bash
.venv/bin/python -m pytest -q tests          # pipeline 單元測試（真實 CWA 資料裁切成的 fixtures）
node tests/e2e/run_e2e.cjs                   # 前端端對端測試（Playwright/Chromium，需先 build）
node tests/e2e/mobile_audit.cjs              # 手機版面檢查：5 種螢幕尺寸的溢出、觸控目標 ≥44px、字級 ≥12px
eslint site/js site/sw.js tests/e2e          # 前端 lint
```

## 部署（GitHub Pages）

1. Repository → Settings → Pages → Source 選 **GitHub Actions**。
   （私人 repository 需 GitHub Pro 以上才能使用 Pages；公開 repository 免費且 Actions 分鐘數不限。）
2. `.github/workflows/build-deploy.yml` 會每 20 分鐘抓資料並部署，也可在 Actions 頁面手動執行。
3. 目前所有資料皆取自氣象署公開 S3，不需要 API 授權碼。若之後加入僅 REST API 提供的資料，請把授權碼放在 Settings → Secrets → Actions 的 `CWA_API_KEY`，**不要寫進程式碼或 commit**。

* 颱風各地區風力／24 小時雨量／總雨量預測表附有氣象署著作權聲明（未經書面授權不得向公眾提供），因此**預設不輸出**，網站改提供[氣象署颱風消息](https://www.cwa.gov.tw/V8/C/P/Typhoon/TY_NEWS.html)連結。個人使用可執行 `python -m pipeline.build --typhoon-tables`；取得授權後在 GitHub Actions Variables 設定 `TYPHOON_TABLES=1` 即可在網站顯示。申請進度見 [docs/TODO.md](docs/TODO.md)。
* 行政區界：[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（MIT，資料來源內政部）。
* 地圖：Leaflet（BSD-2）、OpenTopoMap（CC-BY-SA）、OpenStreetMap、內政部國土測繪中心；OpenCycleMap／Landscape／Outdoors（Maps © Thunderforest，需 API key：在 Actions Variables 設定 `THUNDERFOREST_KEY`，或在網站「設定 → 底圖」填入個人 key）。預設底圖為 Thunderforest Outdoors；未設定 key，或免費額度用完（連續載入失敗）時，自動改用臺灣通用電子地圖並記住 6 小時，之後再試。歷史地圖：中央研究院人社中心「臺灣百年歷史地圖」WMTS（CC BY-NC，僅限非商業使用並須標示出處，商業使用需另洽授權）。底圖可選經建3版 1:25,000 地形圖（2001）；另可在「設定 → 底圖」多選疊加（經建4版 2003 部分更新圖、臺灣歷史人文全覽圖北島），沒有資料的區域透明，露出下方底圖。圖磚網址用 `tileserver/file-exists.php?img=<圖層>-<jpg|png>-z-x-y`（標準 KVP 網址目前回 500）。
* 陣風預報：[Open-Meteo](https://open-meteo.com/)（CC BY 4.0，免金鑰、非商業使用），標示為模式預報、非氣象署發布；顯示在風力圖層說明、登山／鄉鎮預報表的「陣風」列，並納入安全評估。測站體感溫度以氣象署公式（溫度、濕度、風速）估算並標示「估算」。
* 山頭：© OpenStreetMap contributors（ODbL），建置時由 Overpass API 取得 `natural=peak`，每週更新；與氣象署登山預報點同名且 5 km 內者視為同一座、只顯示有預報的那個；下載範圍涵蓋福建沿海，不在臺灣任何鄉鎮界內的山頭（例如福建的同名山）會被剔除。OSM 未填海拔的山頭以 Open-Meteo 地形模型估算並標示「約 N m」。每座山頭附所在縣市鄉鎮（內政部行政區界，經 taiwan-atlas；位於界線 0.4 km 內的山同時列出兩邊，例如「臺中市和平區／苗栗縣泰安鄉」），搜尋結果與面板都會顯示，方便分辨同名山。
* 山頭分類（百岳、小百岳等）：在 `pipeline/data/peak_lists/` 放清單 JSON 即會在建置時標記，格式見該資料夾 README；更新清單不需重新下載 OSM。
* 本工具的安全評估為自動規則判斷，僅供參考，請以現場狀況與官方資訊為準。
