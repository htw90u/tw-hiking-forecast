## 待修

- [x] **溫度圖層與陸地範圍有落差**（2026-10-24 回報，2026-10-27 修正）：溫度分析（O-A0038-003）是只涵蓋陸地、3 km 格點的資料，畫面上海岸線呈階梯狀，沿海有白色缺口，龜山島那一格看起來像海上的色塊。
  - 查證：格點對位本身正確（與縣市界比對，位移不到半格）；問題是格點太粗，沒有套用真實海岸線。
  - 修法：繪圖時先把沿海無資料的格點用鄰近值外推 2 格，再以縣市界（含離島）裁切到真實海岸線，海面不再著色，龜山島等離島保留。
- [x] 沒填海拔的 OSM 山頭（例如觀音山）：建置時以 Open-Meteo 地形模型（Copernicus 90 m DEM）估算，標示「約 N m」並在面板註明「地形模型估計」；OSM 有填的海拔不受影響；估計值只在山頭資料更新時抓取。
- [ ] 山頭分類清單（百岳、小百岳、120 岳、三角點）：格式已預留於 `pipeline/data/peak_lists/`，需要整理含座標的清單與來源授權後放入。
